# Frontend de EduMonitorAI

Estructura inicial del cliente web. El framework, las dependencias y las herramientas de construcción se definirán en una implementación posterior.

## Organización

- `src/app/`: configuración y composición de la aplicación.
- `src/pages/`: páginas y vistas.
- `src/components/`: componentes reutilizables de interfaz.
- `src/services/`: clientes de las API del backend.

Las carpetas contienen archivos `.gitkeep` para conservarlas en Git.

## Estado

No hay funcionalidad, dependencias ni comandos de desarrollo, compilación o pruebas configurados. Este alcance solo inicializa la estructura del repositorio.
